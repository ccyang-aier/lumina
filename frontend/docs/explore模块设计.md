# 「洞察」频道设计方案

> 定位：AI 驱动的前沿技术情报中枢，持续追踪、分析、沉淀技术脉搏

---

## 一、产品定位与设计哲学

「洞察」不是一个普通的内容聚合页，而是**智能神经末梢**。它的核心价值在于：

- **持续性**：后台定时任务 7×24 运转，用户每次访问都有新内容
- **深度性**：不是简单转发标题，而是经过 AI 分析、分类、提炼后的结构化情报
- **个性化**：打上博主视角和判断标签，区别于冷冰冰的算法推荐
- **沉淀性**：每一篇论文、每一次技术浪潮都被记录在案，形成可回溯的技术编年史

整体设计哲学是**「少而精，深而美」**。

## 二、内容体系

### 2.1 五大内容维度

「洞察」承载五类内容，这五类内容不是子菜单，而是**同一页面内通过 Tag/筛选器切换的内容维度**。

#### ① 论文前线
以 arXiv、Semantic Scholar、Papers With Code 为数据源，聚焦推理加速、大模型、多模态、Agent 等方向，每日定时抓取并由 AI 完成：
- 摘要提炼（中文化、通俗化）
- 核心贡献提取（这篇论文解决了什么问题、用了什么方法、效果如何）
- 技术标签自动打标（方向 / 方法论 / 适用场景）
- 重要性评分（基于引用预测、方向热度、创新程度等维度）

每周生成「本周论文趋势报告」，纵向对比同类方向的演进脉络。

#### ② 技术情报
追踪工程实践侧的动态：GitHub Trending、Hacker News 精选、各大厂（Google、Meta、OpenAI、Anthropic 等）技术博客更新、重要开源项目版本发布。AI 处理后输出「这个东西是什么、为什么值得关注、和已有方案有何不同」三段式速读卡片。

#### ③ 行业脉搏
连接技术与商业现实：重要产品发布、融资事件、监管政策、行业报告摘要。帮助读者理解技术背后的产业逻辑，避免「只懂技术不懂方向」的视野盲区。

#### ④ 技术演进谱系
这是洞察频道最具长期价值的沉淀模块。当某一技术方向积累到足够数量的素材后，系统自动生成该领域的「技术谱系页」，包含：
- 该方向的发展时间线（关键节点 + 代表性论文/产品）
- 主流方法横向对比（优劣势、适用条件、性能基准）
- 当前开放问题与未来方向

例如「推理加速技术全景」「KV Cache 演进史」「MoE 架构综述」等，是可以独立成文的深度内容。

#### ⑤ 数据追踪
动态指标的可视化监控：HuggingFace 模型/数据集热榜变化、GitHub Star 增长趋势、特定领域论文发布量趋势、主流模型 Benchmark 排名变迁。以图表形式呈现，直观感知技术社区的关注度迁移。

---

### 2.2 内容的时间粒度

| 粒度 | 内容 |
|------|------|
| 每日 | 论文精选（5~10 篇）、技术情报速览（3~5 条） |
| 每周 | 本周论文趋势报告、重要事件周报 |
| 不定期 | 技术演进谱系深度页（积累触发）、数据追踪图表更新 |

## 三、后台系统设计

### 3.1 定时任务规划

```
[每日 02:00]  抓取 arXiv 最新论文 → AI 分析 → 写入数据库
[每日 06:00]  抓取 GitHub Trending、HN Top → AI 提炼 → 写入数据库
[每日 08:00]  生成「今日精选」推送内容（可选：邮件/RSS 推送）
[每周一 09:00] 生成本周论文趋势报告
[每小时]      HuggingFace / GitHub 热度数据抓取（用于数据追踪图表）
[触发式]      某方向内容积累 ≥ 阈值 → 触发技术演进谱系生成任务
```

### 3.2 AI 处理流水线（五步）

```
原始数据（论文/文章/动态）
    ↓
Step 1：内容提取与清洗（去噪、去广告、结构化）
    ↓
Step 2：语义理解（问题/方法/结论三元组抽取）
    ↓
Step 3：分类打标（方向标签 + 方法论标签 + 难度标签）
    ↓
Step 4：重要性评估（多维度评分，过滤低价值内容）
    ↓
Step 5：卡片化输出（标题 / 一句话摘要 / 核心贡献 / 延伸阅读）
```

### 3.3 人工介入点设计

自动化并不意味着失控，以下节点保留人工干预能力：

- **精选推荐**：AI 打分后，博主可在后台手动提升/降低某篇内容的推荐权重
- **标签纠偏**：支持手动修正 AI 打错的分类标签
- **编辑按语**：博主可对任意内容追加「博主按语」，注入个人判断视角
- **内容屏蔽**：一键屏蔽不符合定位的内容，并反馈给分类模型
- **谱系审核**：技术演进谱系页自动生成后，需博主确认发布，不自动上线

## 四、前端设计规范

### 4.1 整体视觉语言

现代化、高级优雅、特效丰富，鼓励通过通过motion、GASP等前端动效库或者利用新颖的、现代化的CSS特效库等实现高级、美观、动态的UI组件和用户界面。
任何ui设计要兼容白天、黑夜两套主题，确保内容清晰、ui精美、视觉效果好，拒绝ai味太重，设计风格优雅大气，配色方案崇尚黑/白经典简约色系，可在关键ui元素等设计处选择用彩色点缀以增加视觉效果。

### 4.2 洞察首页

#### 整体布局

```
┌──────────────────────────────────────────────────┐
│  Header：洞察 / Insight   副标题说明文字  [日期]   │
├──────────────────────────────────────────────────┤
│  [内容维度 Tag 筛选栏]  全部 / 论文前线 / 技术情报  │
│                         / 行业脉搏 / 数据追踪       │
├───────────────────────┬──────────────────────────┤
│                       │                          │
│   主内容流（左侧 2/3）  │   右侧信息边栏（1/3）    │
│                       │                          │
└───────────────────────┴──────────────────────────┘
```

#### Header 区域
- 大标题「洞察」左对齐，右侧显示今日日期和「上次更新时间」
- 标题下方一行浅色副标题：「AI 驱动的前沿技术情报，每日更新」
- Header 背景使用极淡的网格纹理或颗粒噪声纹理，增加质感，不抢眼

#### Tag 筛选栏
- 横向排列，单行不换行，间距宽松
- 选中状态：强调色背景 + 白色文字，带 `2px` 底部光晕
- 未选中：透明背景 + 次级文字色
- 切换时内容区使用淡入动画过渡，不做跳转刷新（前端过滤）
- 筛选栏右侧预留「搜索」icon，点击展开搜索框（输入框从右向左展开动画）

#### 主内容流（左侧）

内容卡片分为三种形态，根据重要性自动排版：

**① 精选卡（Hero Card）**

每日最多 1~2 张，宽度占满左侧列，高度较大。

```
┌────────────────────────────────────────────────┐
│  [方向标签]  [重要性 Badge: 🔥 高关注]          │
│                                                │
│  论文/内容标题（大字号，1.5 行截断）            │
│                                                │
│  一句话摘要（正文色，2行）                      │
│                                                │
│  核心贡献（3个 bullet，轻灰色，小字号）         │
│                                                │
│  ─────────────────────────────────────────     │
│  [来源 icon] arXiv · 2026-03-29   [阅读全文 →] │
└────────────────────────────────────────────────┘
```

卡片左侧有一条 `3px` 宽的强调色竖线作为视觉锚点。悬停时整个卡片轻微上浮（`translateY(-3px)`）并增强边框亮度。

**② 标准卡（Standard Card）**

左右两列排布，是主要的内容展示形态。

```
┌───────────────────────────────┐
│  [标签] [来源]          [日期] │
│                               │
│  标题（2行截断）               │
│                               │
│  摘要（3行截断，浅色）         │
│                               │
│  [方法标签1] [方法标签2]       │
└───────────────────────────────┘
```

**③ 简报条（Brief Row）**

用于「技术情报」「行业脉搏」这类短消息，不需要展开大卡，用列表行形式呈现：

```
• [icon] 标题文字（一行）   来源 · 时间   [→]
```

多条简报条组合成「简报列表组件」，组件顶部有「今日简报」分组标题。

#### 右侧信息边栏

边栏吸顶（`sticky top`），包含以下组件从上到下排列：

**① 本周趋势摘要卡**
- 一个小型卡片，显示「本周最受关注的 3 个技术关键词」
- 每个关键词旁有热度小火焰 icon + 计数
- 点击关键词触发主内容流的关键词筛选

**② 数据追踪迷你图**
- 用 2~3 个迷你 Sparkline 图表呈现关键指标趋势
- 例如：本周 arXiv 推理加速方向论文数量趋势、某热门项目 Star 增长曲线
- 图表极简，无坐标轴，只有折线 + 起止数值

**③ 技术演进谱系入口**
- 列出已生成的谱系页标题（如「推理加速全景」「MoE 架构演进」）
- 每条带一个小图标和简短描述，末尾有「查看全部」链接

**④ 订阅/RSS 入口**
- 简洁的 CTA：「订阅每日精选」，支持邮件订阅或 RSS

### 4.4 内容详情页

#### 布局

```
┌──────────────────────────────────────────────────┐
│  ← 返回洞察                         [分享] [收藏] │
├──────────────────────────────────────────────────┤
│  标签组  ·  来源  ·  时间                         │
│                                                  │
│  标题（大字号，最多 2 行）                        │
│  一句话摘要（强调色，稍大字号，带左侧竖线）        │
├──────────────────────────────────────────────────┤
│  正文内容区（中心对齐，最大宽度 720px）            │
│                                                  │
│  • 核心问题                                      │
│  • 方法 / 技术路径                               │
│  • 关键结果                                      │
│  • 局限性 / 未来方向                             │
│  • 博主按语（若有）← 用特殊样式区分，带头像      │
│                                                  │
├──────────────────────────────────────────────────┤
│  [阅读原文] [相关内容推荐（3张卡）]               │
└──────────────────────────────────────────────────┘
```

- 阅读进度条：页面顶部 `1px` 高的进度条，随滚动增长，颜色为强调色
- 正文内字体放大到 `17px`，行高 `1.8`，留足阅读空间
- 代码片段（若有）使用深色代码块，`JetBrains Mono` 字体
- 「博主按语」使用与正文不同的背景色（带 `4%` 透明度的强调色背景），搭配头像和「博主视角」标签，视觉上清晰区分 AI 生成内容与人工点评

### 4.5 技术演进谱系页

这是整个洞察频道最具视觉张力的页面，采用**全屏沉浸式**布局。

#### 页面内容区域

**上部：方向概览**
- 大标题 + 一段 AI 生成的方向综述（200字以内）
- 右侧：关键数字（代表性论文数、追踪时长、最后更新时间）

**中部：时间线组件**
- 横向滚动时间线，从左到右按时间排列关键节点
- 每个节点是一个小圆点 + 竖线 + 卡片，卡片悬停展开详情
- 重要节点用更大的圆点 + 强调色标注
- 时间线背景有极淡的水平网格线

**下部：方法对比表**
- 横向可滑动的对比矩阵
- 行：各主要方法/论文；列：关键指标（速度提升、内存占用、适用场景、是否开源等）
- 单元格用颜色深浅表示优劣，直观易读

```
└── 右侧边栏（始终显示）
    ├── 本周热词
    ├── 迷你趋势图
    └── 技术演进谱系入口列表
         ├── 推理加速全景 →（谱系详情页）

         └── ...
```
